## I — 方法骨架

数量比较先明确精确差异还是概略大小。
条形和柱形是基础候选，长类别名可考虑横条。
柱条继承零基线要求，棒棒糖的原文约束另有保留。
成对柱条系列较多时需要检查可读性。
比例符号适合粗略比较和较大值差。
多变量雷达和平行坐标需要读者可理解的排列。
象形图需保持原文要求的完整整数图标。

## A2 — 触发场景

- 精确比较对象金额或数量。
- 长标签和多系列之间选择布局。
- 检查柱条轴起点。
- 审查象形和多变量编码条件。

语言信号包括比较大小 / magnitude comparison、零基线 / zero baseline、长标签条形图 / long label bar chart。

数值大小与精细差异进入本卡。主要看名次时读取ranking-selection，主要看整体组成时读取composition-selection，主要看个体频率形状时读取distribution-selection。

以上为阶段3确定的任务边界，实际触发与输出在阶段4检验。

## E — 执行契约与步骤

### 输入契约

- 对象类别、数值、单位与共同统计口径。
- 比较精度要求、标签长度、系列数及变量数。
- 已有图表的轴起点、排列和编码信息，供审查使用。
- 多变量需要尺度约定；象形图需要每完整图标的数值单位。

数据类型、单位、范围和语义须显式核对。纯选型可接受字段说明，涉及具体数值排列的输出须有可核查数值。实现前置条件缺失时，只交付带条件的候选，并列出待补字段。

### 选型规则

|---|---|---|---|

|p46|数据为非时序且类别名较长时，可优先考虑横向条形。|README.md L307 / Magnitude / Bar|See above同时继承柱形零基线规则，未给出标签长度阈值。|
|p47|成对柱或条允许多序列比较，超过两序列时需要审慎评估阅读困难。|README.md L311 / Magnitude / Paired column|未给出更多序列的布局补救方案。|
|p48|数值差异很大或无需辨认细小差异时，可考虑比例符号。|README.md L325 / Magnitude / Proportional symbol|未给出大小映射公式或跨度阈值。|

### 操作步骤

1. 明确表达目标并核对输入契约。完成标准为必要的字段类型、单位和关系已知。若缺关键目标或字段，输出具体问题并停止确定性选型。
2. 辨别精度、标签、系列数和变量数。完成标准为选择条件可逐项核验。
3. 检查零基线、完整符号与变量排列。完成标准为原图问题和相应规则明确对应。
4. 把每个候选对应到规则与出处。完成标准为说明为何适合当前目标，以及哪些条件尚待满足。多个候选均适合时列出条件差异。
5. 按输出契约交付。完成标准为建议、适用条件、风险和缺口齐全；落入p24、p35、p38等待核查规则时停止该分支并说明原因。

### 输出契约

以表格或等价结构输出下列字段。格式为蒸馏者的交付约定。

|字段|完成标准|
|---|---|
|表达目标|明确读者要看清的关系与重点|
|候选图形|给出与当前输入匹配的候选；待补条件须显式写出|
|变量与口径|说明字段类型、单位及基准、时间、层级或地理结构等必要条件|
|选择依据|对应规则ID或类别导语及原文位置|
|使用限制|记录精度、简化、可读性与未核查分支|
|待补输入与后续动作|缺字段则提出具体问题，缺算法则指出所需实现约定|

请求只涉及选型时，给出有条件的候选即可。请求同时需要渲染、统计计算或推断时，另列实现条件，核对其来源后再执行相应工作。

## 相关能力

also_read列出按条件可补读的能力，当前任务只读取必要项。依赖关系具有方向，对比与组合关系可按需要双向补读。

- contrasts-with，排名与排名变化选型（cap.ft-visual-vocabulary.ranking-selection）。触发条件为次序与数值大小的优先级需要判断。排名以有序位置为重点，数量比较以大小及精细差异为重点。 依据为README L101、L299。
- contrasts-with，整体组成与层级关系选型（cap.ft-visual-vocabulary.composition-selection）。触发条件为组件属于整体，但用户可能只关心组件数值。原文建议只关心组件大小时转向数量类别。 依据为README L238。
- contrasts-with，分布形状与个体值选型（cap.ft-visual-vocabulary.distribution-selection）。触发条件为分组数据需要区分分布形状和汇总值比较。分布关注个体取值与频率，数量比较关注对象大小。 依据为README L129、L299。
