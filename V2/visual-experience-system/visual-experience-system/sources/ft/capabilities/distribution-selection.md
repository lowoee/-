## I — 方法骨架

分布任务同时关心取值及频率。
先判断用户看形状、组间摘要、个体值还是极值范围。
已分箱频数可考虑直方图，明确的分布摘要可考虑箱线图。
复杂分布已有密度信息时，可考虑小提琴图。
个体值可考虑点带或条码，重复值可能遮挡。
年龄性别分组与跨类别范围各有专门图形。
累计曲线的不均衡操作规则待核查，当前保留为参考。

## A2 — 触发场景

- 均值相近但形状不同，需要比较分布。
- 比较多个组的分布摘要。
- 需要看到个体值与重合风险。
- 展示年龄性别结构或跨类别范围。

语言信号包括分布形状 / distribution shape、箱线图 / boxplot、小提琴图 / violin plot。

取值频率、形状和个体分布进入本卡。每个对象只有一个汇总数值且重点为大小时，读取magnitude-selection。累计不均衡操作规则继续待核查。

以上为阶段3确定的任务边界，实际触发与输出在阶段4检验。

## E — 执行契约与步骤

### 输入契约

- 个体观测及分组字段，或明确来源的分布摘要与样本范围。
- 关注形状、摘要、个体或极值范围的任务目标。
- 采用统计摘要时，需给出分箱边界、箱须定义或密度估计等实际要用的规则。
- 变量单位、缺失值处理和分组口径；若仅选型可先列所需统计量。

数据类型、单位、范围和语义须显式核对。纯选型可接受字段说明，涉及具体数值排列的输出须有可核查数值。实现前置条件缺失时，只交付带条件的候选，并列出待补字段。

### 选型规则

|规则|条件及动作|出处|实现前置条件或限制|
|---|---|---|---|
|p17|以直方图表现分布时保持较小柱间隙，使读者识别分布形状。|README.md L135 / Distribution / Histogram|未给出分箱算法或空隙尺寸。|
|p18|需要汇总多组分布时，以箱线图呈现中位数和范围。|README.md L141 / Distribution / Boxplot|未指定箱体、须端、异常值定义，不能视为计算规范。|
|p19|分布无法被简单平均值充分概括时，可考虑小提琴图。|README.md L145 / Distribution / Violin plot|未给出密度估计和带宽规则。|
|p20|人口分布需同时按年龄和性别拆分时，可使用背靠背直方形式。|README.md L149 / Distribution / Population pyramid|未给出分组和性别类别扩展规则。|
|p21|点带图适合展示个体数值，许多点同值时需识别其显示限制。|README.md L153 / Distribution / Dot strip plot|未给出抖动、聚合等补救方法。|
|p22|跨多个类别呈现变化或最小最大范围时，可选点图。|README.md L157 / Distribution / Dot plot|未给出变化点数或区间语义规范。|
|p23|希望显示表中全部数据且突出个别值时，可考虑条码图。|README.md L161 / Distribution / Barcode plot|未给出高亮规则或数据规模限制。|

### 操作步骤

1. 明确表达目标并核对输入契约。完成标准为必要的字段类型、单位和关系已知。若缺关键目标或字段，输出具体问题并停止确定性选型。
2. 辨别形状、摘要、个体、年龄性别或范围目标。完成标准为所需观测或统计量明确。
3. 对照规则表并检查重复点和摘要定义。完成标准为选型限制和实现前置条件逐项列出。
4. 把每个候选对应到规则与出处。完成标准为说明为何适合当前目标，以及哪些条件尚待满足。多个候选均适合时列出条件差异。
5. 按输出契约交付。完成标准为建议、适用条件、风险和缺口齐全；落入p24、p35、p38等待核查规则时停止该分支并说明原因。

### 输出契约

以表格或等价结构输出下列字段。格式为蒸馏者的交付约定。

|字段|完成标准|
|---|---|
|表达目标|明确读者要看清的关系与重点|
|候选图形|给出与当前输入匹配的候选；待补条件须显式写出|
|变量与口径|说明字段类型、单位及基准、时间、层级或地理结构等必要条件|
|选择依据|对应规则ID或类别导语及原文位置|
|使用限制|记录精度、简化、可读性与未核查分支|
|待补输入与后续动作|缺字段则提出具体问题，缺算法则指出所需实现约定|

请求只涉及选型时，给出有条件的候选即可。请求同时需要渲染、统计计算或推断时，另列实现条件，核对其来源后再执行相应工作。

## B — 适用边界

- p24累计曲线与不均衡比较保持非active。
- 箱线图的须端不能自动等同于最小值和最大值，必须明确统计约定。
- 直方图分箱、密度估计和重叠点处理算法需要另外指定。
- 原材料面向新闻图表沟通。来源核查支持本卡限定的选型用途，方法对实际读者的效果仍需后续输出测试。
