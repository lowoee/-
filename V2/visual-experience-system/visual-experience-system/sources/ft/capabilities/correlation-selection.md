## I — 方法骨架

先核对变量类型和希望表达的关系。
两个连续变量可分别用坐标轴定位。
加入第三变量大小时可考虑气泡。
有清楚时间演进的双变量关系可考虑连线散点。
两类别维度的模式可考虑XY热图，数量与比率可考虑柱线组合。
关系表达需审查图注是否越过观察数据所支持的结论。

## A2 — 触发场景

- 选择两个连续变量的关系图。
- 希望加入第三个变量的信息。
- 审查关系图是否诱导因果推断。
- 选择类别矩阵的模式表达。

语言信号包括变量关系 / correlation、散点图 / scatterplot、气泡图 / bubble chart。

变量关系进入本卡，单变量形状进入distribution-selection。双变量随时间演进时可组合time-selection。热图字段为地理网格时读取spatial-selection。

以上为阶段3确定的任务边界，实际触发与输出在阶段4检验。

## E — 执行契约与步骤

### 输入契约

- 每个变量的名称、连续值或类别类型、单位与测量含义。
- 同一观测对象上的配对数据，变量须能一一对应。
- 附加变量的含义；演进关系另需时间顺序。
- 读者关注模式还是细微数量差异，图注拟表达的结论。

数据类型、单位、范围和语义须显式核对。纯选型可接受字段说明，涉及具体数值排列的输出须有可核查数值。实现前置条件缺失时，只交付带条件的候选，并列出待补字段。

|p06|用分别占据一个轴的两个连续变量构建关系图。|README.md L61 / Correlation / Scatterplot|未给出重叠处理或回归计算流程。|
|p07|以柱表达数量，以线表达比率，可用于其关系或随时间变化。|README.md L72 / Correlation / Line + Column|未给出双轴尺度或对齐规范。|

### 操作步骤

1. 明确表达目标并核对输入契约。完成标准为必要的字段类型、单位和关系已知。若缺关键目标或字段，输出具体问题并停止确定性选型。
2. 确认连续或类别、附加大小或时间字段，按规则表选择分支。完成标准为每个变量的视觉作用可说明。
3. 审查因果语言和精度需求。完成标准为观察关系与因果断言有明确依据区分，热图的精度代价已记录。
4. 把每个候选对应到规则与出处。完成标准为说明为何适合当前目标，以及哪些条件尚待满足。多个候选均适合时列出条件差异。
5. 按输出契约交付。完成标准为建议、适用条件、风险和缺口齐全；落入p24、p35、p38等待核查规则时停止该分支并说明原因。

### 输出契约

以表格或等价结构输出下列字段。格式为蒸馏者的交付约定。

|字段|完成标准|
|---|---|
|表达目标|明确读者要看清的关系与重点|
|候选图形|给出与当前输入匹配的候选；待补条件须显式写出|
|变量与口径|说明字段类型、单位及基准、时间、层级或地理结构等必要条件|
|选择依据|对应规则ID或类别导语及原文位置|
|使用限制|记录精度、简化、可读性与未核查分支|
|待补输入与后续动作|缺字段则提出具体问题，缺算法则指出所需实现约定|

请求只涉及选型时，给出有条件的候选即可。请求同时需要渲染、统计计算或推断时，另列实现条件，核对其来源后再执行相应工作。

## 相关能力

also_read列出按条件可补读的能力，当前任务只读取必要项。依赖关系具有方向，对比与组合关系可按需要双向补读。
