# 可视化经验蒸馏实验

本项目把公开的图表设计经验和团队约定转成可引用、可检查的规则，用于审查 PNG、用途说明、CSV 和图形源码。评测集包含 8 张统计图和 4 张团队信息图。下表汇总五组现有产物，其中 V2 对应原交付包。

## 来源选择与两版差异

- **Datawrapper** 的公开教程和案例提供图表选择、视觉编码和误读场景，适合提炼能在数据、图面或源码中核验的检查。案例推导有情境和工具边界，审阅时保留原始定位和适用条件，避免把产品操作方式变成跨工具要求。
- **FT Visual Vocabulary** 按表达任务组织图表选择，为偏差、相关、排名、分布、时间、组成等任务提供统一索引。它擅长回答图形能否表达目标，团队排版、数值口径和来源展示仍由适用条款补充。项目优先使用有明确用法与出处的公开材料，没有扩展成书籍或论文全文库。
- **团队资料包** 提供模型自带知识无法得知的约定。新版明示修订覆盖对应旧条款，其他旧条款继承；明确通过的决议按媒介或受众生效；模板和个人意见作为历史材料复核。例如手机小标题只写主题，PC 大屏允许附结论；脚注 24px 覆盖旧模板的 40px。详见 [冲突处理](V1/冲突处理.md)。

按五组实验的版本命名，V1 和 V2 的主要变化是通用来源从 Datawrapper 切换到 FT skill，并使用独立的单位核验契约。现行 V2 删除了 5 条与调试图有关的历史审查记录，保留原始历史结果供追溯。原交付包还记录了一项边界修订：手机卡片宽度检查先确认测量对象和单位，再比较是否达到要求，避免把 355px 内框直接当成 375px 外层画布。该修订不依赖图表 ID。现有产物没有按时间顺序记录“以 V1 为起点逐项修改后运行 V2”的受控迭代，因此两个版本的分数差不能归因于来源切换或某条修订。

## 系统设计与 Schema

1. **人工与模型协作蒸馏。** 人工设计提示词、筛选来源、确认适用条件并裁决冲突；模型辅助定位和提炼候选检查。已审阅的条目写入来源快照和转换种子，供重复构建。
2. **程序构建和校验。** 校验来源哈希、Schema、ID、出处与关联引用，生成结构化经验库。构建入口复现已编排的来源转换。
3. **按场景检索和审查。** 用组织、图表族、媒介和类别筛选有效条目，排除评测衍生记录。逐图向 Agent 提供 PNG、用途、CSV、源码和检索到的经验。源码按文本读取。Agent 判断具体条件和例外，确认问题输出经验 ID、证据、位置和建议。

| 字段 | 设计理由 |
| --- | --- |
| `id`、`title`、`statement` | 使审查结果能稳定引用规则，人也能快速读懂规则内容。 |
| `status` | 区分有效、被替代、仅供参考、待审与被拒绝，保留追溯链。 |
| `scope` | 表达组织、图表族、媒介、类别、条件与例外，限制规则的适用范围。 |
| `check` | 写明检查问题、所需证据、通过及失败条件和建议动作，减少空泛意见。 |
| `retrieval` | 保存检索关键词和优先级，使适用条目的排序可追踪。 |
| `validity`、`relations` | 记录来源权威、生效时间，以及覆盖、例外和重复关系。 |
| `evidence`、`provenance` | 记录来源 ID、行号、引文和解释，以及提炼方式和是否依赖评测。公开条目的链接与原始定位可沿来源快照回查。 |

### 本地运行

V1 从 `V1` 目录执行。V2 先解压原交付包，在包内项目根目录执行相同命令，将图表路径指向实验目录中的 `测试集`。需要 Python 3.10+、`jsonschema` 和已登录的 Codex CLI。

```powershell
python -m pip install -e .
python -m vizexp build
python -m vizexp validate
python -m vizexp review "D:\data\VIS\可视化经验蒸馏实验\测试集" --organization team-finance --output review.json
```

## 评测边界与蒸馏价值

- [测试集](测试集/) 只提供图表输入。参考意见在输出冻结后用于评分；历史交付 ZIP 不作为模型的审查材料。C 的原文里有与 chart-17、chart-18、chart-19 高度对应的历史评审，团队图 9/9 包含这些线索的优势。V1 也保留相关团队文档用于规则溯源，现有同批图结果不足以判断新图上的迁移表现。
- C 的输入规模较小时，模型可以直接查到具体条款。V1 在团队图上达到了同等覆盖，但通用问题确认数较少。蒸馏的优势更可能出现在资料增多、版本和媒介例外频繁变化、或需要在多次审查中稳定引用同一条规则时。现有产物未测量成本和跨次稳定性。
- 12 张图的参考意见只覆盖预设问题。本报告采用单次语义复核。要验证 V2 的增益是否能迁移，应在另一批图上盲评，固定模型、采样设置、逐图会话和评分口径，并保留输入清单与运行轨迹。修订应来自独立出处和可迁移的适用条件，例如“确认缺单位”和“确认应填什么单位”分开判定。
