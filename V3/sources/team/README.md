# 团队资料包

这是一个虚构团队的内部资料，用来模拟真实工作中经验的样子：散落在不同地方，有新有旧，彼此之间不完全一致。团队名称、人员和数据都是虚构的，但资料的写法和问题的类型来自真实工作。

团队负责在一款面向普通个人投资者的金融 App 里，自动生成财报解读、行情分析之类的信息图。

| 文件 | 内容 |
|:--|:--|
| `信息图制作规范-v1.md` | 2025 年 3 月的第一版规范 |
| `信息图制作规范-v2.md` | 2026 年 6 月的修订版，只写了改动的条款 |
| `评审意见摘录.md` | 设计评审对历史产出的意见，按时间排列 |
| `群聊决议摘录.md` | 工作群里做出的决定和讨论 |
| `模板代码摘录.md` | 生成信息图的模板代码中与版式有关的常量 |

## 使用说明

- 这份资料包是你蒸馏经验的来源之一。你也可以同时使用其他公开来源。
- 资料之间可能存在冲突、过时或只在特定条件下适用的内容，需要你自己判断哪条有效、在什么条件下有效。
- 评测包中的信息图（chart-17 至 chart-20，以及面试现场的同类图）按这个团队的要求审查。统计图（chart-01 至 chart-16）不受这份资料包约束，按通用的可视化原则审查。
