## I — 方法骨架

先确认读者优先关注对象次序。
静态排名可用排序条形或柱形表达。
跨期或跨类别名次变化可用斜率图。
多类目的紧凑排列可考虑点带。
值差很大且精细比较次要时，可考虑有序比例符号。
需要兼顾数值与名次时，可考虑棒棒糖图并标出关注对象。

## A2 — 触发场景

- 展示联赛或产品排行。
- 比较两期名次变化。
- 用紧凑空间展示多类别排名。

语言信号包括排名 / ranking、名次变化 / rank change、排序 / ordered comparison。

有序位置和名次变化进入本卡。数值大小及精细差异进入magnitude-selection。跨期数值趋势进入time-selection；斜率图是否适合由实际编码的量与信息损失决定。

以上为阶段3确定的任务边界，实际触发与输出在阶段4检验。

## E — 执行契约与步骤

### 输入契约

- 对象标识和数值或已有名次，标识须能跨期对应。
- 名次方向，明确较高数值还是较低数值在前。
- 时间或类别对照，及关注对象；并列和缺失名次处理需指定。
- 单位与读者对精确数值比较的要求。

数据类型、单位、范围和语义须显式核对。纯选型可接受字段说明，涉及具体数值排列的输出须有可核查数值。实现前置条件缺失时，只交付带条件的候选，并列出待补字段。

### 选型规则

|规则|条件及动作|出处|实现前置条件或限制|
|---|---|---|---|
|p11|位置比绝对或相对数值更重要时采用排名视角，并可突出关注项。|README.md L101 / Ranking|未给出并列排名或突出项选择规则。|
|p12|用排序后的条形或柱形表达排名。|README.md L105 / Ranking / Ordered bar|未给出升降序方向或并列处理。|
|p13|值差距大或无需分辨细微差异时，可选排序比例符号。|README.md L113 / Ranking / Ordered proportional symbol|未给出大跨度的数值阈值。|
|p14|将点按顺序排列于带上，表达多类目的排名。|README.md L117 / Ranking / Dot strip plot|未给出类目数或点重叠处理规则。|
|p15|需呈现排名随时间或类别变化时，可选斜率图。|README.md L121 / Ranking / Slope|未给出交叉线和并列名次处理。|

### 操作步骤

1. 明确表达目标并核对输入契约。完成标准为必要的字段类型、单位和关系已知。若缺关键目标或字段，输出具体问题并停止确定性选型。
2. 区分单时点排名与跨期变化。完成标准为排序字段、方向和对象对应关系明确。
3. 按精度和空间条件选择排名图。完成标准为图形同时保留次序和需突出的对象。
4. 把每个候选对应到规则与出处。完成标准为说明为何适合当前目标，以及哪些条件尚待满足。多个候选均适合时列出条件差异。
5. 按输出契约交付。完成标准为建议、适用条件、风险和缺口齐全；落入p24、p35、p38等待核查规则时停止该分支并说明原因。

### 输出契约

以表格或等价结构输出下列字段。格式为蒸馏者的交付约定。

|字段|完成标准|
|---|---|
|表达目标|明确读者要看清的关系与重点|
|候选图形|给出与当前输入匹配的候选；待补条件须显式写出|
|变量与口径|说明字段类型、单位及基准、时间、层级或地理结构等必要条件|
|选择依据|对应规则ID或类别导语及原文位置|
|使用限制|记录精度、简化、可读性与未核查分支|
|待补输入与后续动作|缺字段则提出具体问题，缺算法则指出所需实现约定|

请求只涉及选型时，给出有条件的候选即可。请求同时需要渲染、统计计算或推断时，另列实现条件，核对其来源后再执行相应工作。
