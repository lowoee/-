# 团队规则的冲突、继承和例外

以 v2 明示修订覆盖相应 v1 条款，其他条款继承。明确通过且明确修改旧规范的群聊决议按其条件执行。评审意见可解释或印证规则，模板记录实现时点。个人偏好、未采纳提案、孤立案例评审均不单独成为审查要求。

| 分歧 | V1 处理 | 出处与经验 ID |
| --- | --- | --- |
| 小标题要不要附结论 | 手机端只写主题，结论放主标题。PC 大屏允许“主题｜结论”，两种写法均可。 | v1 §1.3、v2 §1.3、群聊 2026-09-03。team-v2-1.3、team-chat-20260903 |
| 脚注间距 40px 或 24px | 以图表区底部至脚注分隔线的 24px 为准。旧模板 40px 带待更新备注。 | v1 §1.4、v2 §1.4、FOOTER_GAP。team-v2-1.4 |
| 折线非零起点是否保留孤立 0 和断轴符号 | 非零起点可用，撤销孤立 0 和断轴符号要求。普通柱状图仍按独立条款保留零基线。 | v1 §2.1/2.2、群聊 2026-08-14。team-chat-20260814、team-v1-2.1 |
| 单位写在数据标签还是单位行 | 点或柱上的标注只写数值，金额、币种和百分号等量纲集中在单位行。拒绝删除全部标注的提案，现有资料也未规定每个点必须标注。 | v1 §3.2、v2 §3.2、群聊 2026-10-11、LABEL_WITH_UNIT。team-v2-3.2、team-proposal-remove-labels |
| 纵轴单位居中还是左对齐 | 保留纵轴上方的位置，单位行左边缘对齐刻度数字最左缘。模板的居中配置仅供追溯。 | v1 §2.3、v2 §2.4、UNIT_ALIGN、评审 2026-08-21。team-v2-2.4 |
| 同类数值不同精度 | 金额显示两位小数，同图同类数值小数位一致。评审中的三位小数主张已被明确驳回。 | v1 §3.1、v2 §3.1、评审 2026-09-10。team-v2-3.1 |
| 市场惯例与受众惯例冲突 | 面向该团队国内投资者且编码涨跌时，各市场统一红涨绿跌。 | v1 §4.2、群聊 2026-07-02、评审 2026-10-09。team-chat-20260702 |
| 用蓝色替代品牌紫 | 保留品牌色，群聊决议作为同一条品牌规范的补充证据。配色数量和表格高亮仍按 v2 检查。 | v1 §4.1、v2 §4.3、群聊 2026-09-20。team-v1-4.1、team-v2-4.3 |
| 量级差与双轴的关系 | 把 v2 §2.5 拆为两个独立检查。不同指标共用一轴时才检查 5 倍拆图阈值。一个绘图区使用两个独立纵轴可单独判定。 | v2 §2.5。team-v2-2.5、team-v2-2.5-dual-axis |
| 来源行对外名称与内部字段 | 脚注写实际来源，隐藏内部字段。报告类列出报告名，行情和模拟数据按其真实来源披露。 | v1 §5.1、v2 §5.2、评审 2026-08-21。team-v1-5.1、team-v2-5.2 |

归并保留原始引用，已替代、参考和被否决记录退出执行检索。2026-08-25 的多线太接近意见是历史案例，资料没有给出通用判定阈值。卡片宽度测量对象、复杂序列的代表量级及无法换算的指标，证据不足时进入待核查。对“5 倍以上”采用包含 5 的读法，并在经验条目中要求列出可比数值与计算。

## 团队经验与 Datawrapper 经验的边界

| 场景 | 联合审核口径 |
| --- | --- |
| 独立双纵轴 | 团队信息图可依据 team-v2-2.5-dual-axis 报告双轴本身。EXP-019 只在把同高、对齐或交点解释为相等、反超等情况核对误读。统计图只执行后者。相同缺陷合并记录。 |
| 数据标注单位 | 团队图依据 team-v2-3.2 把单位集中到单位行。EXP-011 用于核对实际计量角色和换算，可从单位行取单位。 |
| 普通柱零基线与瀑布图 | 普通柱长度按 EXP-007 和适用的 team-v1-2.1 检查。瀑布图为展示差值放大尺度时按 EXP-027 检查总量截断提示，与已裁决的 CON-001 一致。 |
| 品牌配色、涨跌色与系列辨识 | 团队色约定适用时照常检查，EXP-013、EXP-014 另核查系列能否追踪。可通过直接标名等办法兼顾辨识与颜色限制。 |
