# 信息图制作规范 v1.0

- 发布日期：2025-03-10
- 适用范围：App 资讯信息流中的财报解读卡片、行情分析长图

## 1 版式

1.1 手机端卡片宽度 375，左右内边距 16。

1.2 主标题不超过两行，用一句话写出结论，关键词可以用品牌紫高亮。

1.3 小标题推荐使用“主题｜结论”的格式，例如“价格走势｜站上均线”，让读者扫一眼就能拿到结论。

1.4 图表区与脚注之间保留 40px 间距，脚注上方加一条分隔线。

## 2 坐标轴

2.1 柱状图的纵轴必须从 0 开始。

2.2 折线图的纵轴可以不从 0 开始。此时必须在纵轴底部保留 0 刻度，并画上断轴符号，提醒读者坐标被截断。

2.3 单位写在纵轴上方。

## 3 数值

3.1 金额保留两位小数。

3.2 数据标注写全单位，例如“1.25 亿元”“2,818 JPY”，避免读者误读。

## 4 颜色

4.1 主色为品牌紫 `#7B3FE4`，辅助色为蓝 `#3E7BFA` 和浅紫 `#B9A3F0`。

4.2 涨跌色：A 股红涨绿跌。

## 5 来源

5.1 脚注写明数据来源。
